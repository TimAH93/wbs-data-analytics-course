# WBS Data Analytics Kurs

**TL;DR:** Meine Arbeiten aus dem Data-Analytics-Kurs der WBS Coding School:
gelöste Challenges, die Code-Alongs aus dem Unterricht und die dazugehörigen
Datensätze. Ein Ordner pro Kursabschnitt.

## Inhalt

| Ordner | Was drin ist |
|---|---|
| `week-01-02/challenges/` | Meine Lösungen zu den Challenges aus Woche 1–2 |
| `week-01-02/code-alongs/` | Notebooks, die wir im Unterricht gemeinsam geschrieben haben |
| `week-01-02/data/` | Datensätze und Data Dumps, die wir dafür benutzt haben |

Weitere Wochen kommen als eigene Ordner dazu (`week-03-04/` usw.).

## Öffnen

Die meisten Dateien sind Jupyter-Notebooks (`.ipynb`). Öffnen mit Jupyter,
VS Code oder direkt hier auf GitHub (Vorschau ohne Ausführen).

## Hinweis

Die Datensätze stammen aus dem Kursmaterial der WBS Coding School und dienen
nur zum Lernen.
